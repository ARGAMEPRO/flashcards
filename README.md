# Карточки для запоминания

Две части одного проекта: Telegram-бот и веб-версия. Логика одинаковая — карточка с вопросом
и ответом, переворот по кнопке и повтор по интервалам.

## Как считаются интервалы

Упрощённый SM-2, без библиотек:

- **Забыл** — карточка возвращается на завтра, лёгкость падает на 0.2 (но не ниже 1.3).
- **Знаю** — первый раз интервал 1 день, второй 3 дня, дальше умножается на лёгкость (стартует с 2.5),
  потолок — 365 дней. Лёгкость растёт на 0.05, но не выше 2.8.

Карточка, которую забыли, попадает обратно в очередь этой же сессии.

## Бот

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="токен из @BotFather"
python3 bot.py
```

Команды: `/add` — новая карточка, `/review` — пройти то, что пора, `/stats` — цифры,
`/list` — последние десять. Данные в `cards.db` (SQLite), в git не попадает.

## Веб-версия

`docs/index.html` — один экран, без сборки и сервера: карточки хранятся в `localStorage`.
Открыть можно файлом или через GitHub Pages.

Горячие клавиши: пробел — показать ответ, 1 — знаю, 2 — забыл.

## Структура

```
bot.py            бот: FSM для добавления, инлайн-кнопки, SQLite
docs/index.html   веб-версия: разметка
docs/style.css    оформление
docs/app.js       логика: localStorage, интервалы, горячие клавиши
requirements.txt  aiogram 3
```
