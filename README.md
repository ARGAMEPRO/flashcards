# Карточки для запоминания

Две части одного проекта: Telegram-бот и веб-версия. Логика одинаковая — карточка с вопросом
и ответом, переворот по кнопке и повтор по интервалам.

## Бот

Один файл, только стандартная библиотека Python 3 — ни aiogram, ни других зависимостей.

```bash
export BOT_TOKEN="токен из @BotFather"
python3 bot.py
```

Без переменной окружения бот возьмёт токен из `token.txt` рядом с собой.

Команды: `/add` — новая карточка, `/review` — пройти то, что пора, `/stats` — цифры,
`/list` — последние десять. Данные в `cards.db` (SQLite), в git не попадает.

### Что использовано из новых возможностей Bot API

- **Виджет с переворотом.** Карточка приходит как `sendWidget` — HTML внутри сообщения.
  Нажатие на кнопку отправляет `widget_query`, бот отвечает `answerWidgetQuery` и сохраняет
  состояние через `editMessageWidgetData`, так что карточка остаётся перевёрнутой
  после перезагрузки чата.
- **Стилизованные кнопки.** «Знаю» — `style: success`, «Забыл» — `style: danger`.
- **Копирование ответа.** Кнопка `copy_text` кладёт ответ в буфер одним нажатием.
- **Эфемерное сообщение.** Подсказка после переворота приходит по
  `ephemeral_message_parameters` — её видит только нажавший.

Если сервер не поддерживает виджеты, бот сам откатывается на обычное сообщение с кнопкой
«Показать ответ» — переписка не ломается.

## Как считаются интервалы

Упрощённый SM-2, без библиотек:

- **Забыл** — карточка возвращается на завтра, лёгкость падает на 0.2 (но не ниже 1.3).
- **Знаю** — первый раз интервал 1 день, второй 3 дня, дальше умножается на лёгкость
  (стартует с 2.5), потолок — 365 дней. Лёгкость растёт на 0.05, но не выше 2.8.

Карточка, которую забыли, попадает обратно в очередь этой же сессии.

## Веб-версия

`docs/index.html` — карточки переворачиваются в 3D, данные в `localStorage`, без сборки
и сервера. Открыть можно файлом или через GitHub Pages:
[argamepro.github.io/flashcards](https://argamepro.github.io/flashcards/)

Горячие клавиши: пробел — перевернуть, 1 — знаю, 2 — забыл.

## Структура

```
bot.py            бот: виджет-карточка, стилизованные кнопки, SQLite
docs/index.html   веб-версия: разметка
docs/style.css    оформление
docs/app.js       логика: localStorage, интервалы, переворот
```
